# SustainZone Eco Explorer Challenge

Child-friendly interactive app for exhibition use at Hertfordshire County Show 2026.

## Run locally

```bash
npm install
npm run dev
```

## Notes

- Built with React + TypeScript + Vite.
- Uses webcam through browser APIs.
- Generates certificate image download from in-memory content only.
- No backend, no localStorage, and no server data transfer.
